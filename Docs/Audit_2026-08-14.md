## 0. Вердикт

Каркас v0.8 **правильный и не требует смены архитектуры**. Объектные действия (`EditInlineNew` + `Instanced` + каталог-ассет), семантический `Handle*`, `UWorldSubsystem`, карантин Legacy в `DIVERuntimeDev`, GRIP только в sibling-bridge — это зрелый плагин по меркам эталона.

Health pass 2026-08-11 закрыл реальные P0 (мир каталога, `CanExecute` на primary, isolation-pick, overlay, единый валидатор, proxy через continuous-слот). **Повторять те пункты как открытые нельзя.**

Health Pass 2 и Authoring QoL закрыли cut-over швы: CDSO-сид, Definition blend, Scan/FindAnchor по детям, `ExecuteResolvedAction` для меню/primary, chrome empty-hide, hover early-out + preload, Physical Warning, suppress isolate/cycle при меню, Bridge stub log, SharedUtils убран из Bridge Build.cs **и** `.uplugin`, K2 без `LoadObject` всех action BP, Details `Targets: N`.

Remaining DIVE Pass закрыл: B7 name-only match, dual `OnExecuted` fan-out из `NotifyActionExecuted`, Bridge Hand/Aim `FComponentReference` picker, `TryRequestSessionFromActionId` для хост-BP.

Остаток — не «переписать DIVE»:

- **god-объекты** (`UDIVESessionSubsystem` + Ops, `UDIVEInspectableComponent`) — принятый компромисс;
- **хост** EI Content и ручная склейка ACTS→helper на устройствах — не C++ game module;
- **PIE-чеклист** — operational долг, не code debt.

Ниже — статус после проходов, не снимок «до фиксов».

| Решение | Почему это правильно |

## 4. Баги и ловушки поведения

### B1 (P2). Четыре вечных CDSO на каждом Inspectable — **Closed (Health Pass 2)**

Конструктор больше не `CreateDefaultSubobject`. `SeedDefaultBindingsIfNeeded` создаёт `NewObject` с теми же именами субобъектов (`DefaultFocusAction` / Isolate / SimulatePhysics / DeleteMesh), только если `Bindings` пусты.

### B2 (P2). `FocusBlendDuration` выпадает из Device Definition — **Closed (Health Pass 2)**

Поле есть на `UDIVEDeviceDefinitionAsset` и мержится в `GetEffectiveCameraSettings`.

### B3 (P2). Chrome: tooltip врёт, hint не прячется — **Closed (Health Pass 2)**

Пустой `ModeSwitchHint` не подставляет «Switch mode». `RebuildChrome` ставит `Collapsed`, если текст пуст. Мёртвый `SetModeHintVisible` убран.

### B4 (P2). Physical pick без бэкенда — тишина — **Closed (Health Pass 2)**

Провал — `Warning`, не Verbose. Fallback на Default-primary по-прежнему нет (намеренно: Physical ≠ Default).

### B5 (P2). Меню открыто — isolate / cycle — **Closed (Health Pass 2)**

`HandleToggleIsolate` / `HandleCycleInteractionMode` suppress, пока меню открыто. Exit по-прежнему работает.

### B6 (P1). Scan считает якоря только на выбранном акторе — **Closed (Health Pass 2)**

Scan и `FindAnchorNode` fallback ходят по `DIVE::ForEachDeviceActor`.

### B7 (P2). `MatchesComponentNameValue` зовёт `TryResolveStartFocusTarget` — **Closed (Remaining DIVE Pass)**

Component Name — только exact `FName` + `NormalizeComponentToken`. `TryResolveStartFocusTarget` после якоря использует тот же name-token на примитивах (не focus-leak в матч биндингов). PartId/якоря — `EDIVETargetMatchMode::PartId` / `FindAnchorNode`. Details preview и рантайм по-прежнему один путь (`CollectPrimitivesMatchingQuery`). Smoke: `DIVE.Actions.ComponentNameMatch`.

### B8 (не баг плагина). `OpenDIVE` нигде в C++ не вызывает `RequestSession` — **Closed (helper; host BP)**

`DIVE::kActionOpenDIVE` — контрактная константа. ACTS `ExecuteAction` только бродкастит `OnActionExecuted`. Плагин даёт `TryRequestSessionFromActionId` (одна нода QUICKSTART §3). Склейка — BP на устройстве, не `Source/KDP`. EI Content по-прежнему хост.

## 5. Костыли и workarounds (честные и нет)

Не всякий workaround — грязь. Ниже — классификация.

### 5.1. Оправданные (оставить, не размножать)

| Костыль | Где | Почему оправдан |
|---------|-----|-----------------|
| `ExecutionWorld` + RAII scope | `DIVEDeviceAction` | UE не даёт мира asset-hosted инстансу. Альтернатива — клонировать каталог на каждый Inspectable (хуже) |
| `bHiddenInGame` в `IsPrimitivePickable` | Inspectable | `IsVisible()` не отражает isolation |
| Multi-hit + prefer pick-proxy | `DIVEPick` | Visibility trace бьёт в оболочку раньше объёма |
| Сохранение `OverlayMaterial` | PickOps | Hover инвазивен к mesh state |
| `EDIVEPreservedInputMode` эвристика | Input | PC не отдаёт предыдущий `FInputMode` |
| `NormalizeComponentToken` (`_GEN_VARIABLE`, `_123`) | Core | Имена компонентов BP нестабильны |
| `bIgnoreNextPrimaryActionRelease` | Session | LMB-up после клика по строке меню не должен сразу `EndInteraction` |
| Grab re-pin после `TryGrab` | Bridge | GRIP `InitGrabHoldDistanceFromView` уводит руку на view ray; задокументировано в README |
| Stub Bridge без GRIP | Bridge Build.cs | Conditional §7; plugin грузится, drive = `false`; stub `BeginPlay` Warning |

### 5.2. Терпимые, но хрупкие

| Костыль | Риск |
|---------|------|
| `InternalProxyDriveAction` — скрытый инстанс ForwardAction на подсистеме | Авторы его не видят; Physical не идёт через Catalog. Слот общий — хорошо; «магический» объект — плохо для отладки |
| Friend-структуры `FDIVESession*Ops` | Разбиение по файлам, не по инкапсуляции. Любое новое поле = правки 4 файлов в обход API. Accepted |
| `const_cast` в `MakeActionContext` | Const-метод пишет non-const `SourceComponent`. Типичный UE, но граница врёт |
| JSON-regex `IsPluginExplicitlyDisabled` в трёх `Build.cs` (DIVE RuntimeDev, Bridge, ACTS) | Дубль хрупкого парсера `.uproject`. Папка на диске + «не Enabled:false» ≠ «плагин включён в target» |
| Legacy single-Hand hijack в Bridge | Работает на demo-pawn; на двух руках без имени Dive — `nullptr` после одного warning |
| Имя Aim = string replace `"Hand"` → `"Hand Aim"` | Fallback после `FComponentReference` picker и FName. **Closed (picker)** |
| Dual mouse delta: `GetInputMouseDelta` → fallback cursor pos | Два источника правды на orbit и proxy-drag |

### 5.3. Костыли, которые лучше убрать

| Костыль | Статус |
|---------|--------|
| CDSO ×4 (B1) | **Closed** — `NewObject` в сиде |
| `bHasValidPick` на `BuildEntries` | **Closed** — параметр снят |
| 9 `GetEffective*` геттеров | BP-обёртки оставлены; C++ focus берёт struct один раз |
| `friend class UDIVESessionSubsystem` | **Closed** — `NotifySessionLifecycle` public |
| `Action.OnExecuted` **и** `Inspectable.OnActionExecuted` | **Closed** — `NotifyActionExecuted` бродкастит оба; built-ins больше не Broadcast сами |

## 7. Архитектурная грязь

### 7.1. Два god-объекта — accepted

**`UDIVESessionSubsystem`** — сессия, камера, focus stack, isolation, hover, menu cache, proxy/continuous slot, mode, делегаты. Ops — горизонтальный срез файлов. **Не выделять Isolation/Router ради чистоты.**

**`UDIVEInspectableComponent`** — pick, camera merge, semantic registry, binding match, menu builder, validation, hover, seed. Авторский фасад устройства. Не блокер.

### 7.2. Три пути «нажать на деталь»

```text
Default LMB     → PickOps::ExecutePrimaryAction  → ExecuteResolvedAction
Context menu    → ExecuteContextMenuAction       → ExecuteResolvedAction
Physical LMB    → PhysicalDriveOps               → InternalProxyDriveAction ИЛИ pawn bridge
```

Меню и primary **сведены** в `ExecuteResolvedAction` (**Closed**, Health Pass 2). Pawn bridge **намеренно** вне action-системы (cursor-pull). Цена: value-HUD и `OnInteractionValueChanged` на pawn-drag молчат (задокументировано).

### 7.3. Dual authoring: компонент + каталог

Union по секциям — правильное решение. Не упрощать до одного дома.

### 7.4. Dual event model — **Closed (Remaining DIVE Pass)**

| Канал | Кто слушает |
|-------|-------------|
| `UDIVEDeviceAction::OnExecuted` | Fan-out из `NotifyActionExecuted` (не built-in `Execute`) |
| `UDIVEInspectableComponent::OnActionExecuted` | K2 DIVE Action Event; тот же choke |
| `OnSessionLifecycle` на Inspectable | Input/UI сидят на subsystem delegates |

K2 ExpandNode не менялся. Continuous notify по-прежнему на **Begin**, не End.

K2 binding: `FindFunctionByName` + silent `continue` при ренейме графа — событие умрёт без compile error.

### 7.5. Editor → RuntimeDev

**Closed (Health Pass 2):** `DIVERuntimeDev` — PrivateDependency Editor-модуля (Dump в том же меню, что Scan).

### 7.6. Core — не «тонкие типы»

`DIVECore` тянет Engine. Это shared gameplay contract, не CoreUObject-only.

Камерные дефолты живут в трёх местах: `DIVEConvention.h`, `FDIVECameraEffectiveSettings`, UPROPERTY Inspectable / DeviceDefinition.

### 7.7. `UDIVEDeviceDefinitionAsset` — камера (+ blend)

Имя обещает definition. По факту — камера/орбита **включая** `FocusBlendDuration`. Hover и pick остаются per-instance. Переименование в `DIVECameraSettingsAsset` — Won't-fix this pass.

## 8. Разрывы между системами

```text
ACTS ExecuteAction("OpenDIVE")  ──BP──►  TryRequestSessionFromActionId
ACTSRuntime                      не знает DIVE
ACTSRuntimeDev                   poll IsSessionActive каждый tick (не делегат)

DIVERuntime  ──IDIVEPawnPhysicalDrive──►  DIVEGRIPBridge  ──GRIP Hand API──► GRIP
DIVERuntime  не шлёт ScreenDelta на pawn bridge (контракт cursor-pull)
Value HUD    не получает значения с pawn-drag

Hover overlay            ──/ /──  Physical mode (намеренно Default-only)
Catalog primary          ──/ /──  Physical LMB (намеренно proxy/bridge)

KDP Source               ──/ /──  DIVE (ноль символов; GRIP в Look — да)
Demo pawn dual Hand      ──/ /──  FindComponentByClass vs named Dive slot
```

Закрытые внутри DIVE: Definition ↔ blend, Scan ↔ hierarchy, chrome empty-hide, menu suppress isolate/cycle, hover no-material early-out, FindAnchorNode children, Bridge stub log, B7 name match, dual events fan-out, Hand/Aim picker.

### 8.1. Внутри DIVE (остаток)

| Стык | Симптом | Статус |
|------|---------|--------|
| Isolation pick-proxy | Изоляция volume оставляет **все** mesh видимыми (документировано) | Accepted |
| Continuous `OnActionExecuted` | Стреляет на **Begin**, не на End | Won't-fix this pass |
| B7 Component Name match | См. §4 | **Closed** |

### 8.2. DIVE ↔ GRIP / Bridge

Контракт cursor-pull выдержан. Разрыв продуктовый: `IDIVEProxyDrive` даёт value-HUD; GRIP pawn-drag — нет. Hand/Aim: `FComponentReference` picker, FName и `"Hand "` → `"Hand Aim "` — fallback. Stub без GRIP логирует Warning в `BeginPlay`.

### 8.3. DIVE ↔ ACTS

Shipping ACTS не знает про модальную сессию. Production-guard — BP хоста на `TryRequestSessionFromActionId`. Dev-suspend — poll, не `OnSessionStarted`.

### 8.4. DIVE ↔ хост

Нормативный путь (EI Content + BP) в репозитории **не представлен исходниками**. PIE держится на `UDIVELegacyKbmInputComponent`. Аудит плагина не подтверждает таблицу `IA_DIVE_*` в Content.

## 10. Удобство: что чувствует автор устройства

Путь «100 болтов → Unscrew BP → Catalog» — один из лучших в трёх плагинах: фабрики, GetOptions, combo PrimaryAction, `Targets: N`, Scan, Dump, K2 event, Condition.

Где всё ещё трёт:

1. **Pawn stack из 4–6 компонентов** без wizard.  
2. **Hover молчит без материала** — Scan/QUICKSTART предупреждают; pick при этом жив.  
3. **PartId ≠ имя компонента** — tooltip + Scan.  
4. **Physical без registry** — легко промахнуться в GRIP-drag.  
5. **События** — закрыто Remaining Pass: K2 DIVE Action Event; `OnExecuted` фанится из `NotifyActionExecuted`.  
6. **Filtered K2 node** (BindingId): дублирование wildcard-ноды. Работает, неочевидно.
